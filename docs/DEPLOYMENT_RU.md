# Деплой версии с localStorage

Supabase, SQL, авторизация и `DEFAULT_PORTFOLIO_ID` больше не нужны. Существующая база не изменяется, старые сделки из неё автоматически не переносятся.

1. В Vercel используется репозиторий `elcin31/assetmind-v031`, ветка `main`.
2. Настройки Vite и сборки уже в `vercel.json`. После обновления репозитория проверьте автоматический деплой. Если он отключён, выполните Redeploy последнего коммита.
3. Откройте постоянный адрес приложения и добавьте покупку с тикером и ценой вручную.
4. Обновите страницу: сделка должна сохраниться. Экспортируйте резервную копию кнопкой Export backup.

`FINNHUB_API_KEY` нужен только для поиска, котировок и исторических цен. При отсутствии ключа ручной учёт продолжает работать, рыночная оценка может быть неполной.

Данные хранятся отдельно для каждого браузера и адреса сайта. Очистка данных сайта удаляет портфель. Для переноса используйте Export backup / Import backup; импорт объединяет сделки без удаления текущих. В приватном режиме данные могут исчезнуть после закрытия сессии.

Проверки: `npm ci`, `npm run verify`. `npm run smoke` проверяет доступность страницы, сохранение сделки проверяется в браузере.
